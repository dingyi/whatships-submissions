# whatships-submissions

This repository collects submissions for [What Ships](https://whatships.com) — a curated directory of product launch videos from X.

本仓库通过 GitHub Issues 收集 [What Ships（whatships.com）](https://whatships.com) 的投稿：产品发布视频、工具、工作室和独立设计师。

## How to submit / 如何投稿

- Easiest: use the form at <https://whatships.com/submit/>. It opens a prefilled issue here.
  最方便：用 <https://whatships.com/submit/> 的表单，它会在这里打开一个预填好的 issue。
- Or [open a launch video submission](https://github.com/dingyi/whatships-submissions/issues/new?template=launch-video.yml) directly.
  或者直接[新建一个发布视频投稿](https://github.com/dingyi/whatships-submissions/issues/new?template=launch-video.yml)。

Every submission is reviewed by a human before anything is published. Nothing here is published automatically.
所有投稿都会经过人工审核，不会自动上线。

This repository holds no catalog data; it only receives issues.
本仓库不存放任何目录数据，只用来接收 issue。
